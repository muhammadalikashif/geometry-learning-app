# Geometry Learning App

An interactive geometry learning platform built with **Streamlit**. Users can explore different geometric shapes, solve area calculation problems, track progress, and earn achievements.

## Features 

- **Learn Geometry** : View explanations and formulas for different shapes.
- **Practice Problems** ✏️: Solve random area calculation problems.
- **User Authentication** : Register, log in, and track personal progress.
- **Gamification** : Earn points, level up, and unlock achievements.
- **Progress Tracking** : View solved problems, accuracy, and leaderboard.
- **Database Storage** : Uses SQLite for storing user data and progress.

## Installation 

### **1. Clone the Repository**
```bash
git clone https://github.com/muhammadalikashif/geometry-learning-app.git
cd geometry-learning-app
```

### **2. Install Dependencies**
Make sure you have Python installed, then install the required packages:

```bash
pip install -r requirements.txt
```

### **3. Run the App**
```bash
streamlit run app.py
```

## How to Use 

1. **Register/Login** to save your progress.
2. **Explore Shapes** in the learning section.
3. **Practice Problems** by solving randomly generated area calculations.
4. **Earn Points & Achievements** for correct answers.
5. **Track Your Progress** on the progress dashboard.
